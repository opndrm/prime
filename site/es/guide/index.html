OPEN DREAM PRIME · GUÍA DEL EQUIPO

EMPIEZA
TRANQUILO.

Una guía práctica para tu primer espacio Open Dream Prime: desde una computadora nueva hasta tu primera tarea enfocada.

OBTENER LA INSTALACIÓN

01 · TU ESPACIO

UNA PERSONA.
UNA APP.

Open Dream Prime crea OPNDRM APP, un espacio nuevo en tu Escritorio. Tu computadora, credenciales y sesiones de Prime son tuyos. El equipo colabora mediante Buzz y GitHub, no compartiendo una terminal o credenciales.

02 · INSTALAR

INSTALA
EN MAC.

En una Mac, copia este comando de OPNDRM APP en Terminal e ingresa tu contraseña de administradora de Mac cuando se solicite.

sudo -v && curl -fsSL https://opndrm.com/install-macos.sh | bash -s -- OPNDRM-APP

Si faltan las herramientas de línea de comandos de Apple, el instalador abre Actualización de software. Si Apple requiere primero una actualización de macOS, complétala y reinicia si se solicita; después ejecuta otra vez el mismo comando de OPNDRM. Si no, instala allí las herramientas de línea de comandos y el instalador continúa automáticamente. Para ADAM o FRNKLY.ONE, abre el navegador para que la persona inicie sesión con su propia cuenta de GitHub antes de clonar el proyecto privado. Luego configura WezTerm, HERDR, Prime Agent, Ollama, No Mistakes, Buzz, Git y un espacio nuevo de OPNDRM APP en tu Escritorio. No recopila secretos, aprueba la confianza del Vault, sobrescribe un espacio existente ni inicia No Mistakes.

Atomic Vault sigue siendo un paso completado por el propietario hasta que se configure la fuente de instalación aprobada.

03 · LA PANTALLA

CONOCE TU
ESPACIO.

PrimeLa sesión principal de Prime Agent. Dale una tarjeta de trabajo limitada a la vez.
No Mistakes GateUn punto de calidad visible y reservado. Permanece inactivo hasta que el flujo aprobado del repositorio lo use.
BuzzLa conversación compartida para personas y agentes. Discute el trabajo allí; no coloques contraseñas ni credenciales privadas.
WayfinderEl plan del Issue de GitHub. Registra decisiones, responsable, alcance y el siguiente trabajo.

04 · PRIMERA TAREA

UNA TARJETA
A LA VEZ.

  1. Abre el Issue de GitHub que se te asignó en Wayfinder.
  2. Lee su objetivo, área de producto o archivos y la comprobación de aceptación.
  3. Abre el checkout del proyecto correspondiente en WezTerm.
  4. Dile a PRIME el resultado limitado que necesitas: una función, reparación o investigación.
  5. Mantén el branch, la revisión y el estado conectados al Issue de GitHub.

05 · MODELOS

OLLAMA ES
LOCAL.

PRIME puede usar DeepSeek Flash, MiniMax M3 y cada modelo instalado en tu catálogo local de Ollama. Elige un modelo para el trabajo actual. La configuración local de Ollama no es una clave de API compartida ni permite que otra persona acceda a tu computadora.

06 · CREDENCIALES

EL VAULT ES
PERSONAL.

Atomic Vault y su límite CBF Remote protegen tus propias credenciales. Completa tú mismo el inicio de sesión oficial y el paso de confianza del propietario. Nunca pegues contraseñas, tokens, códigos de recuperación ni claves privadas en PRIME, Buzz, Issues de GitHub o archivos del proyecto.

07 · PEDIR AYUDA

MANTÉN AL EQUIPO
INFORMADO.

Usa Buzz para preguntar a un compañero sobre contexto o una decisión. Usa Wayfinder para aclarar el alcance o registrar la decisión. Usa GitHub para el código, branch, revisión y registro final. Si la instalación se detiene, comparte el mensaje de error simple con el equipo; nunca una contraseña o credencial.
