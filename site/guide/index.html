GET THE INSTALL

01 · YOUR WORKSPACE

ONE PERSON.
ONE APP.

Open Dream Prime creates OPNDRM APP, a fresh workspace on your Desktop. Your computer, credentials, and Prime sessions stay yours. Teamwork happens through Buzz and GitHub—not by sharing a terminal or a credential.

02 · INSTALL

INSTALL
ON MAC.

On a Mac, copy this OPNDRM APP command into Terminal and enter your Mac administrator password when asked.

sudo -v && curl -fsSL https://opndrm.com/install-macos.sh | bash -s -- OPNDRM-APP

If Apple Command Line Tools are missing, the installer opens Software Update. If Apple requires a macOS update first, complete that update and restart if asked, then run the same OPNDRM command again.

03 · THE SCREEN

KNOW YOUR
WORKSPACE.

PrimeThe main Prime Agent session. Give it one bounded work card at a time.
No Mistakes GateA visible, reserved quality checkpoint. It remains inactive until the approved repository workflow uses it.
BuzzThe shared conversation for people and agents.
WayfinderThe GitHub Issue plan. It records decisions, owner, scope, and the next work.

04 · YOUR FIRST TASK

WORK ONE
CARD AT A TIME.

  1. Open the GitHub issue you were assigned in Wayfinder.
  2. Read its goal and acceptance check.
  3. Open the matching project checkout in WezTerm.
  4. Tell PRIME the bounded outcome you need.
