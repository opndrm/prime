OPEN DREAM PRIME · TEAM GUIDE

START
CALM.

A practical guide for your first Open Dream Prime workspace—from a new computer to your first focused piece of work.

GET THE INSTALL

01 · YOUR WORKSPACE

ONE PERSON.
ONE APP.

Open Dream Prime creates OPNDRM APP, a fresh workspace on your Desktop. Your computer, credentials, and Prime sessions stay yours. Teamwork happens through Buzz and GitHub—not by sharing a terminal or a credential.

02 · INSTALL

INSTALL
ON MAC.

On a Mac, copy this OPNDRM APP command into Terminal.

curl -fsSL https://opndrm.com/install-macos.sh | bash -s -- OPNDRM-APP

If Apple Command Line Tools are missing, the installer starts Apple’s request and opens Software Update directly. Install Command Line Tools there; the installer then resumes automatically. It next sets up WezTerm, HERDR, Prime Agent, Ollama, No Mistakes, Buzz, Git, and a fresh OPNDRM APP workspace on your Desktop. It does not collect secrets, approve Vault trust, overwrite an existing workspace, or start a No Mistakes run.

Atomic Vault remains an owner-completed step until the approved installer source is configured.

03 · THE SCREEN

KNOW YOUR
WORKSPACE.

PrimeThe main Prime Agent session. Give it one bounded work card at a time.
No Mistakes GateA visible, reserved quality checkpoint. It remains inactive until the approved repository workflow uses it.
BuzzThe shared conversation for people and agents. Discuss work there; do not put passwords or private credentials in it.
WayfinderThe GitHub Issue plan. It records decisions, owner, scope, and the next work.

04 · YOUR FIRST TASK

WORK ONE
CARD AT A TIME.

  1. Open the GitHub issue you were assigned in Wayfinder.
  2. Read its goal, files or product area, and acceptance check.
  3. Open the matching project checkout in WezTerm.
  4. Tell PRIME the bounded outcome you need—one feature, repair, or investigation.
  5. Keep the resulting branch, review, and status attached to the GitHub issue.

05 · MODELS

OLLAMA IS
LOCAL.

PRIME can use DeepSeek Flash, MiniMax M3, and every model installed in your local Ollama catalog. Choose a model for the work in front of you. Ollama’s local placeholder configuration is not a shared team API key and does not give another person access to your machine.

06 · CREDENTIALS

VAULT STAYS
PERSONAL.

Atomic Vault and its CBF Remote boundary protect your own credentials. Complete the official owner sign-in and trust step yourself. Never paste a password, token, recovery code, or private key into PRIME, Buzz, GitHub Issues, or a project file.

07 · ASK FOR HELP

KEEP THE TEAM
IN THE LOOP.

Use Buzz to ask a teammate about context or a decision. Use Wayfinder to clarify scope or record the decision. Use GitHub for the code, branch, review, and final work record. If installation stops, share the plain error message with the team—never a password or credential.
