# Open Dream Prime onboarding — English

Use this sequence with a new teammate.

1. Ask which workspace they need: OPNDRM APP for a new build, ADAM, or FRNKLY.ONE.
2. Have them use the installer from opndrm.com. On a Mac without Apple Command Line Tools, it opens Software Update directly; install Apple Command Line Tools there and leave Terminal open for automatic continuation. On Windows, clearly identify the installer as a first-device preview. If Windows App Installer is missing, it opens Microsoft Store and the person reruns the same command after that prerequisite is installed. The official Buzz installer appears in its own visible window.
3. Confirm that their checkout is their own and has not overwritten another project.
4. Open their matching local HERDR session and PRIME workspace: `opndrm-opndrm-app`, `opndrm-adam`, or `opndrm-frnkly-one`. This restores the last saved session for that app on Mac or Windows.
5. Explain the visible roles: PRIME builds; No Mistakes Gate remains idle; Buzz is conversation; Wayfinder is the GitHub Issue plan; GitHub is the code record.
6. Let the employee complete their own Atomic Vault sign-in and trust step. Do not handle or request their credentials.
7. Start the first task from one Wayfinder issue. State its outcome, scope, quality check, and stop condition.

If setup stops, report the plain blocker. Never ask a teammate to paste a password, token, recovery code, or private key.
