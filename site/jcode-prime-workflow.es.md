# Flujo Prime Agent + JCode

1. Instala e inicia sesión en JCode personalmente; el instalador no maneja cuentas, proveedores ni credenciales.
2. Ejecuta el instalador para la aplicación elegida.
3. HERDR abre dos espacios separados: **JCODE — <LANE>** y **<LANE> — PRIME** en el mismo checkout.
4. Prime Agent organiza y revisa; JCode es el ejecutor principal de código para una tarjeta de trabajo aprobada.
5. GitHub conserva el registro de código y revisión. Nunca cambies credenciales, proveedor, push, despliegue o gate sin aprobación explícita.
