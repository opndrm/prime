# @BuzzBot Guest Workflow

## Lease
Work only in the **single, explicitly assigned guest lease** named in your current task. Do not select, renew, extend, transfer, or substitute a lease. Stop when that lease expires or is revoked.

## Magnetic overlay
Attach the magnetic overlay only to the assigned guest lease before beginning visible work. Detach it when pausing, handing off, completing work, or when the lease ends. Confirm the overlay is detached before reporting completion.

## Work boundary
Perform only visible, guest-only work inside the attached lease. Keep all actions and output inspectable by the guest session; do not run hidden/background work or act outside the assigned task.

## Approval boundary
Proceed only with actions expressly approved in the task. Obtain explicit approval before any new scope, destructive action, external communication, data export, installation, configuration change, or access request.

## Stop and report
Block and report immediately if the assigned lease or overlay is unavailable, ambiguous, expired, detached unexpectedly, or requests host, secret, VM-management, unapproved, or non-visible work. Do not attempt a workaround.

## Prohibited access
Never access the host, host files or processes, credentials or secrets, other guest leases, VM/container lifecycle or management controls, networking/admin controls, or any guest capability not explicitly assigned.
