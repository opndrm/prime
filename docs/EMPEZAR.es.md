# Incorporación de Open Dream Prime

1. Elige un lane: OPNDRM APP, ADAM o FRNKLY.ONE.
2. Ejecuta el instalador de macOS desde opndrm.com. Se detiene antes de sobrescribir un checkout existente.
3. Para un lane privado, inicia sesión con tu propia cuenta de GitHub y obtén acceso normal al repositorio antes del clon.
4. Confirma la sesión HERDR visible, Prime Agent en la raíz correcta y la Gate de No Mistakes visible e inactiva.
5. Completa tú mismo el inicio de sesión de Buzz. Conecta un agente solo con aprobación explícita.
6. Da a Prime Agent una tarjeta de trabajo limitada. Mantén código y revisiones en GitHub.

El instalador no instala ni configura modelos, credenciales, dashboards, ejecuciones remotas ni sandboxes.
